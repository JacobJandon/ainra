# Internet-Drafts

| Draft | Status |

| [`draft-georgiev-agent-key-status-00`](draft-georgiev-agent-key-status-00.md) | Written 2026-10-29. Not submitted. |

**draft-georgiev-agent-key-status** specifies the link record (D-078) for any implementer: proof of control by the
linked key, the three kinds of revocation, the fixed verification order, and reuse of the IETF Token Status List for the
status itself. It is aimed at the OAuth, Web Bot Auth and agentproto working groups, as an individual submission.

The source is kramdown-rfc markdown. To produce the XML and text versions and check them before submitting:

```
gem install kramdown-rfc && kdrfc docs/ietf/draft-georgiev-agent-key-status-00.md
```

Submitting is the author's step, through the IETF datatracker. Nothing here has been sent anywhere.
