# v0.3.1 — preflight board evidence (M26)

The FULL preflight board, run from a **clean `git clone` at the release commit `d5f3a3d`** — the proof
`docs/DECISIONS.md` D-040 and `RELEASING.md` require before v0.3.1 is tag-ready.

v0.3.1 is a **security release**: it fixes RUSTSEC-2025-0144 (timing side-channel in `ml-dsa` `decompose()`) and
closes the class of never-running CI check that hid it. See [`../_archive/plans/PLAN-M26.md`](../_archive/plans/PLAN-M26.md) for the full
workings and [`../../SECURITY.md`](../../SECURITY.md) for the public post-mortem.

Two rows are new since v0.3.0:

* **`cross-impl interop`** — material signed *now* by the upgraded crate, verified by `@noble/post-quantum` and by
  OpenSSL, each required to refuse a flipped bit. It exists because the regenerated corpus came out byte-identical
  after the upgrade, which makes "the vectors still pass" an easy test to pass.
* **`browser verifier`** — the full 745-vector corpus through the compiled WASM in a headless browser.

Reproduce it yourself:

```sh
tmp="$(mktemp -d)"; git clone -q <repo> "$tmp/clone"
( cd "$tmp/clone" && git checkout -q d5f3a3d && cargo fmt --all -- --check && make preflight )
```

## Negative controls — proof each gate can also go RED

A green row only means something if the same check can fail. Recorded here because M26 found three checks in this
repository that had never once passed (`scorecard` never resolved its action, `clusterfuzzlite` never built, and
`cargo-audit` short-circuited past the very advisory this release fixes).

```text
cargo-audit         ignore removed        → exit 1, RUSTSEC-2023-0089, "1 denied warning found!"
clusterfuzzlite     targets build AND run → canon 2,819,057 · passport 2,365,037 · tsl 589,127 execs / 21 s, no crashes
browser verifier    make wasm-diff-negative        → 744/745, exit 1
cross-impl interop  make interop-negative          → exit 1 (one corrupted signature byte)
one decode path     planted duplicate parser       → caught
```
