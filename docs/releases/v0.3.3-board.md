# v0.3.3 — the board at the release commit

`make preflight` from a **fresh public clone** of `github.com/JacobJandon/ainra` at `6bded81`, per
[`RELEASING.md`](../../RELEASING.md) § *The one rule*. Run 2026-08-09.

Not a reused build directory: the v0.3.3 board was first run in one, and a stale generated `site/status.md`
left there by an earlier run turned the board red for a claim its source had already stopped making. The
gate was corrected to read sources rather than generated artifacts, and this run starts from `git clone`.

Three rows are new since v0.3.2 — `lockfile sync`, `soak ingest` and `one decode path`'s neighbours —
each added because something that had never been checked turned out to be broken.
