# v0.4.0 — the board at the release commit

`make preflight` from a **fresh clone** at `6acf069`, per
[`RELEASING.md`](../../RELEASING.md) § *The one rule*. Run 2026-09-11.

**37 rows, ALL GREEN, no skips.** Six rows are new since v0.3.3, and every one exists because something
that had never been checked turned out to be broken:

- `engine parity` — `site/verify.html` ran two verifiers that disagreed on the same bytes, and the one
  that accepted let the presenter name the verifier (D-051).
- `number syntax` — pins a divergence that is **expected to differ** between implementations (D-054);
  it fails if the divergence widens, narrows, or is quietly "fixed" in one place.
- `doctrine` — ten rules that were enforced only by memory, each proven ungated by committing the
  violation and watching the board stay green (D-057).
- `amendment path` — constitutional and normative text cannot change without a dated record (D-056).
- `honest decay` — the published record must state its own staleness without anyone editing copy (D-058).
- `format legibility` — a parser written from `WIRE-FORMAT-PRIMER.md` alone, importing no AINRA code,
  must reproduce the corpus (D-061).

This is the release that carries the **breaking** PoP wire-format change (D-049): a proof captured from an
honest presentation could be forwarded with a different credential minted to the same instance key at the
same audience. Credentials minted under 0.3.x must be re-minted.
