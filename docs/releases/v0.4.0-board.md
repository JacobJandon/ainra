# v0.4.0 — the board at the release commit

`make preflight` from a **fresh clone** at `be30933`, per
[`RELEASING.md`](../../RELEASING.md) § *The one rule*. Run 2026-09-13.

**37 rows, ALL GREEN, no skips.**

This board was recorded twice, and the reason is worth keeping. The first run was green at the CHANGELOG commit —
but committing this very file took the board-proven release count from five to six, and three site surfaces still
said "five". CI caught what the local run could not: status-consistency had been run *before* the evidence file
existed. **The act of recording the proof invalidated a claim that counts the proofs.** The count was corrected and
the board re-run here, at a commit where it is stable.

Six rows are new since v0.3.3, each added because something that had never been checked turned out to be broken:
`engine parity`, `number syntax`, `doctrine`, `amendment path`, `honest decay`, `format legibility`.

This is the release carrying the **breaking** PoP wire-format change (D-049): a proof captured from an honest
presentation could be forwarded with a different credential minted to the same instance key at the same audience.
Credentials minted under 0.3.x must be re-minted.
