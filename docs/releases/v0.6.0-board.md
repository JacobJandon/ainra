# v0.6.0 — the board at the release commit

`make preflight` from a **fresh clone** at `ed4cfde`, per
[`RELEASING.md`](../../RELEASING.md) § *The one rule*. Run 2026-11-02.

**44 rows, ALL GREEN, no skips.** `ed4cfde` is the commit the signed tag `v0.6.0` is to point at, so this board
attests the tagged tree itself. Tagging and publishing are the maintainer's steps; until they happen, npm and PyPI
serve 0.5.0.

A first run of this board, earlier the same day, went red on two rows — link parity and the browser verifier — with
`Disk quota exceeded`: the machine's temporary space was full of earlier clean clones, not a code failure. It was
stopped, the space freed, and the board re-run from a new fresh clone at the same commit. This is that run.

What this release carries is the CHANGELOG's 0.6.0 section: Link for secp256k1 keys (ES256K, D-082), a decision log
whose cut tail is visible once its head is logged at a registrar (D-081), the public demo door for links,
`@ainra/mcp` depending on the SDK it was released with, and test replay moved out of the paths that decide.
