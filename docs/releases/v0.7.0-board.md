# v0.7.0 — the board at the release commit

`make preflight` from a **fresh clone** at `be0891e`, per
[`RELEASING.md`](../../RELEASING.md) § *The one rule*. Run 2026-11-04.

**48 rows, ALL GREEN, no skips.** `be0891e` is the commit the signed tag `v0.7.0` is to point at, so this board
attests the tagged tree itself. Tagging and publishing are the maintainer's steps; until they happen, npm and PyPI
serve 0.6.0.

A first run of this board, earlier the same day, went red on one row — the browser verifier — because it was run with
`TMPDIR` pointed at a directory on the home disk (to keep the clone's temporary files off a nearly full `/tmp`), and
the headless browser aborts at launch with its temporary directory there. The same row passed (1153/1153) at the same
commit with the default temporary directory. Space on `/tmp` was freed and the whole board re-run from a new fresh
clone at the same commit, with nothing changed. This is that run.

What this release carries is the CHANGELOG's 0.7.0 section: the corpus runners out of the package roots, currency mode
in every gate, a witness a stranger can run, A1 only on a checked principal proof, a negative control for every gate,
five new fuzz targets, and `@ainra/edge` ready for its first publish.
