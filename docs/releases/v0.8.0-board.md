# v0.8.0 — the board at the release commit

`make preflight` from a **fresh clone** at `543d55c`, per
[`RELEASING.md`](../../RELEASING.md) § *The one rule*. Run 2026-11-07.

**60 rows, ALL GREEN, no skips.** `543d55c` is the commit the signed tag `v0.8.0` points at, so this board attests the
tagged tree itself. On the operator's instruction, the tag and the publishes to npm and PyPI follow this board.

A first run of this board, the same day, went red on one row, the operator report. The release commit had changed
the version that `reports/monthly/2026-11.md` records, and the report had not been regenerated in it. The report was
regenerated and folded into the release commit, which had not been pushed. The board was then re-run from a new
fresh clone at the corrected commit. This is that run.

What this release carries is the CHANGELOG's 0.8.0 section:
- the fixes from the first independent adversarial review (D-104);
- portability between registrars (D-102) and change of owner (D-103);
- a gate's own policy (D-100);
- the remote emergency ceremony (D-101);
- the steward's desk (D-099), distrust on proof (D-098), and the witnessed epoch log (D-097).
