The core, drawn

Everything orbits the root.

Every check resolves inward, to the center, and out again — so trust earned anywhere is trust recognized everywhere.

THE ROOT — AINRA

Holds the keys, the rules, the revocation feed, and the logs. Everything below chains up to it, so every check stays local and fast.

RING 1 · INDEPENDENT REGISTRARS

Separate organizations, accredited under identical published rules — licensed issuers, enterprise directories bridging internal identity to the public root, permissionless chains for the open ecosystem.

RING 2 · AGENTS

Every agent carries a passport chained to the root. Running copies use short-lived local credentials under it, so scale stays at the edge.

RING 3 · VERIFIERS

Anyone deciding whether to trust an agent — verifying inward against cached root keys (the dashed rays), each setting its own floor.

Integrate · onboard

Status disclosure. AINRA is a neutral, non-profit root for AI-agent identity, currently pre-genesis. The open standard (v5.1) is public; the reference CLI (v0.1.0) is downloadable and checkable today; the full reference implementation is engineering-complete, pre-release — three implementations agree on all 745 CC0 conformance vectors, and revocation propagation is measured under 60 seconds in a local drill. Verification is offline-capable and free, permanently, and phones home to no one. Canonical live status: status.html.

  
The genesis root is minted: a recorded FROST 5-of-9 + SLH-DSA ceremony produced a real dual-root, the network runs under it, and passports verify root-dark — trusting only the root (run make genesis-verify). This is an operator-run genesis; the distributed public ceremony across independent custodians, three or more external verifiers, and a 14-day multi-region soak are the remaining real-world milestones before it is the production root everyone shares. The passport above is a labeled specimen. The root issues no passports, computes no scores, holds no personal data, features no company, and sells nothing: charter prohibitions enforced in code.
