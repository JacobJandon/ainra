/02 · WHAT A DEMO COVERS

Four steps, on real cryptography.

  1. IssueA registrar issues a passport and writes it to its public log before it is valid./1
  2. VerifyYour stack checks it offline: seven checks, a verdict or a named reason./2
  3. RevokeOne bit in a signed list; each verifier refuses within the freshness class it chose./3
  4. GateThe middleware turns the verdict into an HTTP decision on your route, fail-closed./4
